# RM230 V12

RM230 V12 is a modern Windows optimization and gaming utility built for performance, customization, and ease of use. Designed to help users get more out of their systems, whether they're running a high-end gaming rig or an everyday PC.

## Download

Download the latest version from the Releases page.

* Latest Release: [Releases](../../releases)
* Platform: Windows 10 / Windows 11
* Architecture: x64

Simply download the latest release and run the exe.

## Features

**Game Library** — organize, search, categorize, and launch your games from one place.

**Performance Optimization** — apply gaming-focused Windows optimizations with automatic restoration after gameplay.

**FPS Monitoring** — track FPS and system performance in real time.

**Performance Profiles** — switch between Balanced, Performance, and Gaming configurations.

**Game Discovery** — automatically scan folders and import installed games.

**Recent & Favorites** — quickly access recently played and favorite games.

**Themes** — use built-in themes or set your own wallpaper.

**Safe Tweaks** — reversible optimizations with built-in recovery and rollback protection.

## Privacy

RM230 has no telemetry, analytics, or user tracking. It only accesses its own files and any game folders you choose to add to your library. Nothing about your games, settings, or activity is collected or sent anywhere.
